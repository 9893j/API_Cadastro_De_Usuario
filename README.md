#  Cadastro de Usuários - FullStack

Aplicação FullStack para gerenciamento de usuários, com integração completa entre frontend e backend.

Este projeto foi desenvolvido com o objetivo de aprofundar conhecimentos em tecnologias modernas, utilizando React com Vite no frontend e Prisma como ORM no backend, proporcionando uma arquitetura eficiente e flexível para a construção de APIs e interfaces dinâmicas.

O propósito também é explorar ao máximo essas ferramentas, entendendo como elas se comportam em arquiteturas mais complexas, que exigem integração entre diferentes camadas, garantindo uma base sólida para o desenvolvimento de aplicações escaláveis, organizadas e resilientes.

## 🧠 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar a construção de uma aplicação completa, envolvendo:

- Criação de API REST
- Integração com banco de dados
- Consumo de API no frontend
- Tratamento de erros reais (CORS, conexão, estrutura)

---

## ⚙️ Funcionalidades

- ✅ Cadastro de usuários
- ✅ Listagem de usuários
- ✅ Filtro por parâmetros (nome, email e idade)
- ✅ Exclusão de usuários
- ✅ Integração frontend + backend

---

## 🛠️ Tecnologias utilizadas

### 🔹 Frontend
- React (Vite)
- Axios
- CSS (customizado)

### 🔹 Backend *(privado)*
- Node.js
- Express
- Prisma ORM
- MongoDB
- Cors
